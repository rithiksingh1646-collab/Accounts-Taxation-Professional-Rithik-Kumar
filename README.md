# Rithik Kumar — Personal Portfolio

## Deploy on GitHub Pages
1. Create a GitHub repository named `rithik-portfolio`.
2. Upload `index.html` and `.nojekyll`.
3. In Settings → Pages, choose Deploy from a branch, branch `main`, folder `/ (root)`.
4. Open the generated `https://YOUR-USERNAME.github.io/rithik-portfolio/` URL.

## Connect to LinkedIn
Add the live URL to LinkedIn → Profile → Contact info → Website, and also Profile → Add profile section → Featured → Add a link.
